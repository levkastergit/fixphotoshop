# FixPhotoshop

Программа для Windows, которая следит за Photoshop, ловит зависание при запуске Camera Raw, определяет, где именно завис процесс, и по очереди применяет исправления с возможностью отката.

Ничего устанавливать не нужно: используется .NET Framework, встроенный в Windows 10 и 11. Права администратора обычно не требуются.

## Как пользоваться

1. Скачайте архив: зелёная кнопка **Code → Download ZIP**, затем распакуйте его.
2. Запустите `FixPhotoshop.exe`. Если Windows покажет «Система Windows защитила ваш компьютер», нажмите **Подробнее → Выполнить в любом случае**: у файла нет цифровой подписи.
3. Запустите Photoshop.
4. Откройте Camera Raw как обычно.
5. Если Photoshop не отвечает 20 секунд или показывает окно с ошибкой, программа сама снимет данные и напишет вывод. Если она ничего не заметила, нажмите **Зависло сейчас**.
6. Нажмите кнопку **Применить: …**. Программа закроет зависший Photoshop и выполнит шаг.
7. Запустите Photoshop и откройте Camera Raw снова. Программа сама определит, помог ли шаг. Если зависание повторится, она предложит следующий. Если ошибка появлялась на конкретном действии (например, на размытии), повторите его и, когда ошибки не будет, нажмите **Заработало**.

Отчёт сохраняется на рабочий стол в файл `FixPhotoshop-report-….txt`. Если не поможет ни один шаг, этот файл пригодится для дальнейшего разбора или для поддержки Adobe.

## Что она проверяет

- **В момент зависания:** какие окна не отвечают, стек каждого потока (внутри какого модуля он стоит), цепочки ожидания и взаимные блокировки, загрузку процессора потоками, сторонние модули внутри Photoshop, состояние видеокарты через `nvidia-smi`.
- **В системе:** версии и даты установки Photoshop и Camera Raw, видеокарты и драйверы, журналы Windows (зависания и сбои Photoshop, ошибки видеодрайвера, диска и оборудования, аварийные перезагрузки), что устанавливалось за последние три недели, файлы и журналы Camera Raw.

Если при слежении завис весь компьютер, при следующем запуске программа сопоставит это с записью Windows об аварийной перезагрузке.

## Какие шаги она применяет

Порядок зависит от того, что показала диагностика. Шаги, которые не помогли и чем-то мешают, откатываются автоматически.

| Шаг | Что делает | Как откатить |
|---|---|---|
| ИИ-модели заново | Переименовывает папки `ModelZoo`, Camera Raw скачивает модели снова | Автоматически, если не помогло |
| Другая сеть для моделей | Вручную: мобильный интернет или VPN | Не требуется |
| Мощная видеокарта для Photoshop | Записывает настройку Windows «Высокая производительность» | Автоматически, если не помогло |
| Сброс проверки видеокарты | Убирает `Camera Raw GPU Config.txt` и файлы `TempDisableGPU*` | Кнопка отката |
| Проверка без видеокарты | Создаёт `TempDisableGPU3`, и Camera Raw запускается без GPU | Автоматически, если не помогло |
| Закрытие оверлеев | Закрывает программы, чьи модули найдены внутри Photoshop | Запустить их снова |
| Кэш Camera Raw | Переименовывает папку кэша | Кнопка отката |
| Кнопка Reset GPU Support | Вручную, при окне с ошибкой (шаг Adobe для Camera Raw 17.5+) | Не требуется |
| ИИ-функции на процессоре | Вручную: файл `DisableGPUInference.txt` со страницы Adobe | Удалить файл |
| Сброс настроек Camera Raw | Вручную, по инструкции в программе | Настройки не восстанавливаются |
| Пресеты и профили | Временно переименовывает папки | Автоматически, если не помогло |
| Настройки Photoshop | Временно переименовывает папку настроек | Автоматически, если не помогло |
| Драйвер NVIDIA Studio | Вручную, по инструкции | Поставить прежний драйвер |
| Запуск без сторонних плагинов | Вручную, удержанием Shift | Действует один сеанс |
| Откат Camera Raw | Вручную, по инструкции | Установить новую версию |

Программа ничего не удаляет. Файлы и папки переименовываются рядом с оригиналом с приставкой `fixphotoshop-bak-`. Кнопка **Откатить все изменения** возвращает всё как было. Фотографии программа не трогает.

## Ограничения

- Программа тестировалась на имитации Photoshop: процессе с настоящим окном, которое зависает в разных режимах. На реальном Photoshop с видеокартой NVIDIA она пока не проверялась.
- Вывод опирается на имена модулей в стеке. Он показывает, где завис процесс; причина может быть глубже.
- Создание `TempDisableGPU3` для отключения GPU основано на описании этого файла в FAQ Adobe. Сама Adobe не предлагает создавать его вручную. Новые версии Camera Raw могут требовать видеокарту для части функций.
- Антивирус может насторожиться: программа читает состояние другого процесса и не подписана. Исходный код лежит в `src/`.
